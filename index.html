事前準備

本製品を使用する前に、必ず以下のPC設定およびゲーム内設定を完了させてください。

VALORANTの画面モードを「ウィンドウフルスクリーン」にする（必須）

オーバーレイ機能およびメニューを正常に表示するため、VALORANTのグラフィック設定で表示モードを「ウィンドウフルスクリーン（Windowed Fullscreen）」に設定してください。

メモリ整合性を有効にする（必須）

本製品を動作させるには、メモリ整合性保護（HVCI）を有効にする必要があります。ほとんどのPCでは、この機能はデフォルトで有効になっています。

方法:

  1. Win + I を押して設定を開きます。
  2. プライバシーとセキュリティ → Windows セキュリティ に移動します。
  3. デバイスのセキュリティ をクリックします。
  4. コア分離の詳細 をクリックします。
  5. メモリ整合性 を「オン」にして有効化します。
  6. パソコンを再起動してください。
注：これはWindowsのデフォルト設定です。以前別の製品で無効にしていた場合は、再度有効にする必要があります。
ウイルス対策ソフトを無効にする

ローダーを実行する前に、Windows Defenderのリアルタイム保護機能とサードパーティ製のウイルス対策ソフトをすべて無効にしてください。

VALORANTが実行中の場合は終了してください

ローダーを起動する際は、ゲームが実行されていない状態にしてください。まずVALORANTを完全に終了させて​​ください。

Discordでハードウェアアクセラレーションを無効にする

オーバーレイを表示するには、Discordのハードウェアアクセラレーションをオフにする必要があります。ローダーはこれを自動的にチェックします。

方法:

  1. Discordを開く
  2. 左下にある歯車アイコン（ユーザー設定）をクリックします。
  3. 下にスクロールして「詳細設定」をクリックします。
  4. 「ハードウェアアクセラレーション」をオフにする
  5. Discordが再起動を促したら「OK」をクリックします。
Discordオーバーレイを有効にする（必須）

Discordはゲーム内オーバーレイを有効にした状態で実行する必要があります。ESPやその他のビジュアルはDiscordのオーバーレイを通して表示されます。

方法:

  1. Discordを開く
  2. 歯車アイコン（ユーザー設定）をクリックします。
  3. 「ゲームオーバーレイ」（アクティビティ設定内）に移動します。
  4. レガシーオーバーレイがオフになっていることを確認してください。
  5. 「ゲーム内オーバーレイを有効にする」をオンにする
  6. プレイ中はDiscordを起動したままにしておく
オーバーレイが表示されない場合：
• Discordの任意のボイスチャンネルに参加する
• ゲームオーバーレイ → 詳細設定でVALORANTがブロックされていないことを確認してください。
• Discordを再起動してゲームを再起動する
FACEITをアンインストールする（インストールされている場合）

FACEITアンチチートがローダーをブロックします。インストールされている場合は、完全にアンインストールしてからPCを再起動してください。

使用方法ガイド

VALORANT FULLの導入手順および使用方法です。

1. 必要なファイルのインストール

まず、以下のWebサイトから必要なコンポーネントをすべてインストールしてください。

  • https://proswipexyz-sys.github.io/install/

2. セットアップおよび起動手順

  1. https://ez-val.com にアクセスする。
  2. アカウント（UsernameとPassword）を設定して登録する。
  3. 登録完了後、ログインする。
  4. ログイン完了後、VALORANTタブに移動し、一番下の VALORANT FULL の Activate key に受け取った有効なライセンスキーを入力して Active を押す。
  5. 完了したら Download ボタンを押してローダーがダウンロードされるのを待つ。
  6. ダウンロード完了後、ローダーを管理者権限で実行する。自動でWebsiteに飛ばされるので、現在有効なライセンスキーを選択し、Launch ボタンを押す。
  7. 全てのプロセスがエラーなく完了したら、Enterキーを押してValorantを起動する。
  8. Valorantのロビー内で Insert キー（キーボードにない場合はスクリーンキーボードを使用）を押す。
  9. メニューが表示されるので、そこから設定してプレイ可能。

トラブルシューティング

よくあるエラーや不具合の対処法まとめです。

FPSの低下・動作が重い

以下の機能はFPSを特に消費しやすいため、設定を見直すことでパフォーマンスが向上します。

【FPSを最も消費する機能（負荷が大きい順）】

  1. 長距離でのオブジェクト/戦利品ESP
    — 解決策：最大距離スライダー（Max Distance）を下げてください。
  2. 光る骨格の輪郭（スケルトンアウトライン）
    — 解決策：アウトラインを無効にするか、太さを小さくしてください。
  3. 画面外の矢印（Offscreen Indicators）
    — 解決策：不要な場合は無効にしてください。
  4. レーダー（広範囲ズーム）
    — 解決策：ズーム範囲を狭めるか無効化を試してください。
  5. GPUを使用するバックグラウンドアプリ
    — 解決策：Discordオーバーレイ、ブラウザ、OBSなどの不要なアプリを終了してください。
ヒント：「戦闘モード（Combat Mode）」を使用すると、戦闘中に不要なビジュアル機能を自動的に非表示にしてパフォーマンスを維持できます。
HWIDが一致しません (HWID Mismatch)

ライセンスキーは、最初に使用されたPCのハードウェア（HWID）に紐付けられています。

PCを買い替えたり、Windowsを再インストールしたりした場合は、Webサイト画面右下にあるAIサポートチャットを使ってHWIDのリセットをリクエストしてください。ボットが本人確認を行い、自動的にリセットを完了します。

メニューが表示されない

キーボードの INSERT キーを押してください（ほとんどのキーボードでは矢印キーの上にあります）。

  • ゲームウィンドウへのフォーカス: メニューを開く前に、まずゲーム画面を一度クリックしてフォーカスを合わせてください。
  • ノートパソコンをご利用の場合: Fn + INSERT キーを試してください。
  • 60%キーボード等の場合: キーボードレイアウトによってINSERTキーの割り当てや組み合わせ（Fn + Esc など）が異なります。お使いのモデルのショートカットをご確認ください。
ESPが表示されない

以下の設定・確認を行ってください：

  1. ゲームが始まるまで待つ: エージェント選択画面が終わった後の実際のラウンド（フル装備時）から描画が開始されます。
  2. Visualsタブの確認: メニューの「Visuals」タブを開き、ESP機能自体が有効化されているかチェックしてください。
  3. 最大距離スライダーの確認: 「Max Distance（最大距離）」スライダーの設定値が低すぎないか確認してください。
  4. 味方ESPの設定: 味方のESPはデフォルトでオフになっています。チームメイトを表示したい場合は個別に有効化してください。
サインイン失敗エラー

ほとんどの場合、PCの時計の同期がずれていることが原因です。

修正方法：

  1. 設定 → 時刻と言語 → 日付と時刻 を開く
  2. 「時刻を自動設定する」を一度オフにする
  3. 2〜3秒待ってから、再びオンに切り替える
  4. 「今すぐ同期」ボタンをクリックする
  5. ローダーを再起動する

※問題が解決しない場合は、インターネット接続を確認し、別のDNSサーバー（1.1.1.1 または 8.8.8.8）を試してみてください。

サーバーに接続できませんでした

ローダーの動作にはインターネットへの直接接続が必要です。

  • VPNやプロキシを無効にしてください。
  • Windowsファイアウォールやセキュリティソフトが、ローダーの実行ファイル（発信接続）をブロックしていないか確認してください。
  • 可能であれば別のネットワーク回線を試してみてください。
Windows バージョン関係エラー

Windows Updateをお試しください。
